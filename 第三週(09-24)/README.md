# 第三週（09/24）：感測器與自駕反應獨立示範

目前提供已完成的獨立教學工具與操作說明；第三週三節課的完整簡報、講稿與學生講義仍在調整。

- `第三週_感測器與自駕反應示範.html`：下載後以 Chrome 或 Edge 開啟，可離線操作。可切換中文與越南文，一次顯示一種語言。
- `第三週_模擬教學_使用說明.md`：授課流程、操作步驟、模型規則、資料來源與教師口說示範。

## 最快的操作方式

1. 開啟 HTML，確認版本 v8；預設越南文，可按右上角「中文」切換。以下以中文介面說明。
2. 展開「其他影響條件」，按「恢復基準條件」，再按藍色「機車切入・30 km/h 一鍵比較」。不必先按開始，會自動設定 C 場景、30 km/h、光達 60 m、雷達 80 m，依序播放四組感測器組合，每組保留 GNSS。
3. 播放時觀察道路、各感測器讀值與決策。可暫停解說、調整播放速度，或按「直接看結果」。四組全部完成後才顯示結果。
4. 「行駛反應」顯示起始距離、第 2 秒車速與整段曲線；基準條件下完整組合為 30.0、僅相機約 19.2 km/h。這是距離不確定程度與控制規則造成的結果。
5. 按「回到手動操作」，選不同雨勢或其他條件，再比較。同一配置及外部條件重跑，模型結果可重複。

一般比較按鈕保留比較前的手動進度；藍色一鍵比較會取代原手動設定與紀錄，但沿用目前的全部外部條件。四種固定配置不跟隨手動勾選，皆安裝相機與 GNSS；選了定位遮蔽時，GNSS 仍會在指定時間缺少有效定位。

## 雨勢與外部條件

上方可選晴天、陰天、小雨、中雨、大雨、夜間、逆光眩光與濃霧。「其他影響條件」另提供：

- 鏡頭水滴：無水滴、局部、大片遮蔽。遮蔽位置畫在相機圖上，也會讓影像與類別資料缺漏。
- 光達保護罩：乾淨或髒污／積水，影響有效範圍、有效點與留距。
- GNSS 訊號：正常或第 4–8 秒遮蔽中斷。本課缺少有效定位時減速停下；不是下雨就必然失去 GPS。
- 路面：乾燥或濕滑，最大煞車減速度由 4 改為 2 m/s²，停車規劃也會預留相應空間。
- 控制反應延遲：0.4、0.8、1.2 秒；與只改觀看快慢的播放速度不同，會影響行駛反應。

改條件會回到第 0 秒並暫停，感測器勾選保留。可用「大雨＋鏡頭水滴」快捷設定先示範，再恢復基準、一次只改一項。收起設定後仍顯示條件摘要；投影模式也能展開操作。

## 怎麼看感測器受到的影響？

比較結果可切換「行駛反應」與「感測資料可用性」。天候或感測器表面劣化時，預設先顯示資料可用性：

- 首次新資料時間、新資料缺漏率、最長中斷，以及相機類別／燈色缺漏率。
- 時間軸：有色表示取得新資料，灰色表示有觀察機會卻缺漏，白色不在評估區間。窄螢幕可在時間軸與表格內橫向捲動。
- 展開「各感測通道的缺漏率」，可查看光達、雷達及相機類別資料。未安裝的通道顯示 —。

每 0.1 秒評估主要行人／機車，B 場景改為號誌顏色；基準範圍與視角內、未被公車擋住才計入分母。n 為樣本數，舊資料追蹤不算新資料，各組自車位置不同可能造成 n 不同。分母與控制規則的詳細說明收在 i 圖示和使用說明。

車速接近不代表資料相同。相機缺少類別時，其他通道仍可能提供距離；只有距離不能自動當成已辨認行人，也不能補號誌顏色。已追蹤的前方物體中斷過久時，本課先減速停下等待重新確認。

切換語言與結果頁不重新計算或清除進度。圓形 i 圖示支援滑鼠停留、Tab 與點選固定；按 Esc 或點外部關閉。載入真實影片時，影片和模型各自播放，數值只對應圖示模型。

所有天候、資料劣化、限速、煞車與延遲數值均為課堂設定，不是實測雨量或廠商規格。模型沒有執行真實影像辨識、完整波動散射、ABS、輪胎打滑或衛星多路徑；不能用它排名真車感測器或安全性。

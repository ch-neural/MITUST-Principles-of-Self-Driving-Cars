目前提供已完成的獨立教學工具與操作說明；第三週三節課的完整簡報、講稿與學生講義仍在調整。

- `第三週_感測器與自駕反應示範.html`：下載後以 Chrome 或 Edge 開啟，可離線操作。可切換中文與越南文，一次只顯示一種語言。
- `第三週_模擬教學_使用說明.md`：教師授課流程、各活動操作、觀察與結論。

## 最快的操作方式

1. 開啟 HTML，確認版本為 v6；預設越南文，可按右上角「中文」切換。以下按鈕名稱以中文介面說明。
2. 按上方藍色「機車切入・30 km/h 一鍵比較」。不必先按「開始／繼續」。程式自動設定場景、車速與範圍，從時間零依序播放四種感測器組合，每組都保留 GPS／GNSS。上方會標示目前第幾組及感測器配置。
3. 播放時同步觀察道路動畫、各感測器讀值和決策。可以按「暫停比較」解說、調整播放速度，或按「直接看結果」略過動畫。C 場景四組以 1× 播放約一分鐘；全部結束後才顯示比較表。① 是起始距離資料；② 是第 2 秒實際車速；③ 是車速曲線，虛線標示第 2 秒。數值會自動擷取，不必手動計時。
4. 看第一列與有底色的影像組：這個固定設定下，第 2 秒車速分別為 30.0 與 19.2 km/h。這是模型依距離不確定程度採取不同目標車速的結果。
5. 播放中按「取消比較」，或完成後按「回到手動操作」，會恢復比較前的設定與進度，保持暫停。可再個別調整感測器、車速與範圍，或觀察紅綠燈和公車遮擋場景。

切換語言會保留目前模擬進度、設定、四組播放狀態與已算出的比較結果；瀏覽器允許儲存時會記住上次選擇。投影與比較畫面也保留語言按鈕。

GPS／GNSS、感測器畫面與操作區旁的圓形「i」圖示，滑鼠停留、點擊或用 Tab 選取即可顯示說明；按 Esc 或點其他位置關閉。GPS／GNSS 說明明列：關閉定位時，本模型會減速停下。要測試僅以相機感知前方，請保留「相機＋GNSS」。

一般操作列的「比較四種固定組合」按鈕使用當下選擇的場景、目標速度與範圍；會暫停目前這輪，另從時間零依序執行四組固定配置，返回後保留原輪資料。要測試手動取消相機，應回到手動操作後按「開始」。

此工具使用幾何量測與預先設定的控制規則。± 數值為模型留距範圍，不是通用感測器精度；結果用於理解資料、決策與反應，不能當成真車安全測試或硬體效能排名。載入真實影片時，影片與模型各自播放，數值只對應圖示模型。

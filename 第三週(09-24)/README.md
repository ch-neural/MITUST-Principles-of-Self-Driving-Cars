## v9：看見行駛結果

開啟 HTML，確認版本 **v9**；預設越南文，可按右上角「中文」切換。以下以中文介面說明。

先按一個實驗按鈕，讓同學預測，再按「開始／繼續」觀看：

| 按鈕 | 課堂設定與本輪結果 |
| --- | --- |
| 實驗：行人來不及停 | E 場景，30 km/h、濕滑路面、1.2 秒控制延遲；即使已有行人資料，約第 3.2 秒仍碰撞行人 |
| 實驗：無法保持車道 | F 場景，中雨、大片水滴、無法辨識標線、強橫向擾動，資訊不足仍繼續；約第 4.7 秒車體外緣越過車道邊界 |
| 實驗：資訊不足停車 | 同樣的 F 與差環境，改「減速／停車」策略；約第 2.5 秒已接近停止，本輪未偏離車道 |

快捷鍵只設定條件，不會自動播放或直接指定事故。結果依位置重疊、車道邊界、延遲與控制計算；碰撞或偏離後停止本輪，另記錄紅燈越線、資訊不足停車與急煞。

按「改用良好條件對照」再開始，保留場景、車速、感測器勾選、量測範圍及橫向擾動，改用清楚影像／標線、正常定位、乾燥路面、0.4 秒延遲與基準策略。上述行人實驗可停下禮讓，車道實驗可保持在車道內。這些是特定配置的可重複結果；改參數後應看重新計算的結果。

## 比較感測器組合

1. 選 A–F 場景，設定環境與其他條件，直接按一般「比較四種固定組合」，不必先按開始。
2. 程式從第 0 秒依序播放四組；每組保留相機與 GNSS，不跟隨手動勾選。可暫停、調播放速度或直接看結果。
3. E、F、橫向擾動、對照策略或記錄事故時，預設顯示「行駛結果」：事件與時間、最大中心偏移、最大減速度及判定依據。
4. 可切到「行駛反應」看起始距離、第 2 秒車速與曲線；或「感測資料可用性」看首次新資料、缺漏率與中斷。

一般比較保留原手動進度，完成或取消後還原並暫停。上方藍色「機車切入・30 km/h 一鍵比較」會取代原手動設定與紀錄，切到 C、30 km/h、光達 60 m、雷達 80 m，沿用外部條件；**E、F 實驗請用一般比較按鈕**。缺少 GPS 的手動實驗也請用開始按鈕，固定比較皆保留 GNSS；設定遮蔽時仍會短暫失去有效定位。

## 外部條件與資訊不足策略

上方可選晴天、陰天、小雨、中雨、大雨、夜間、逆光眩光與濃霧。展開「其他影響條件」可改：

- 鏡頭水滴、光達保護罩髒污／積水：影響有效範圍、點數、影像及類別資料。
- GNSS 第 4–8 秒遮蔽中斷：另設的訊號遮蔽情境，不是下雨就必然失去 GPS。
- 乾燥／濕滑路面：最大煞車減速度由 4 改為 2 m/s²，規劃也預留相應空間。
- 0.4／0.8／1.2 秒控制延遲：指令等待後才作用，會改變行駛；與觀看快慢的播放速度不同。
- 資訊不足策略：基準為減速／停車；對照策略不因資料缺失而預先停車，但仍對已取得的障礙物或紅燈資料反應。
- 清楚／模糊／無法辨識的標線，以及第 2–8 秒橫向擾動：可觀察相機車道位置與簡化控制反應。

改條件會回到第 0 秒並暫停，感測器勾選保留。課堂可先用快捷實驗，再一次只改一項找出影響；差的條件可能使車停下，不一定造成事故。

## 解讀資料與模型範圍

資料時間軸有色表示新資料、灰色是有觀察機會卻缺漏、白色不在評估區間。每 0.1 秒評估主要行人／機車，B 改為燈色；基準範圍與視角內、未被公車擋住才計入分母。舊資料追蹤不算新資料，各組自車位置不同可能造成樣本數不同。

F 則評估相機車道位置與 GNSS 定位；GPS 仍有新資料，不代表資料足以保持車道。**本版只使用相機與有限的 GNSS 輔助做車道保持，沒有由光達／雷達提取車道**，也沒有完整轉向、車身偏航、輪胎或風力學模型。勿用其結果排名真車感測器或 GNSS 控制能力。

切換語言與結果頁不重新計算或清除進度。圓形 i 支援滑鼠停留、Tab 與點選固定；按 Esc 或點外部關閉。窄螢幕可在結果表格內橫向捲動。載入真實影片時，影片和模型各自播放，數值只對應圖示模型。

所有天候、資料劣化、限速、煞車與延遲數值均為課堂設定，不是實測雨量或廠商規格。模型沒有執行真實影像辨識、完整波動散射、ABS、輪胎打滑或衛星多路徑；某一輪沒有事故，也不保證所有條件下安全。

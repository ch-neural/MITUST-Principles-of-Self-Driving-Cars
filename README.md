## 下載與上課使用

在 GitHub 點選 **Code → Download ZIP**，解壓縮後開啟所需週次的資料夾。請先下載檔案，再用桌面版 PowerPoint、Word 或 PDF 閱讀器開啟。

第二週上課依序使用 `第二週_第1節_簡報.pptx`、`第二週_第2節_簡報.pptx`、`第二週_第3節_簡報.pptx`。

第一節簡報與 `第1節_分級練習_30題隨機抽題.html` 必須保留在同一個資料夾。若 PowerPoint 未開啟抽題網頁，可直接以 Chrome 或 Edge 開啟該 HTML；抽題活動可離線使用。

照片、圖例與感測器動畫已內嵌於教材，不必另外下載製作素材。GIF 動畫請使用 PowerPoint 桌面版的「投影片放映」觀看，PDF 和 GitHub 預覽無法播放動畫。第二週案例與感測器影片採線上連結，播放需要網路。

## 教師與學生文件

教師可使用 PowerPoint 備忘稿與各節 DOCX 講稿備課。部分備忘稿依授課需求另行調整，簡報內備忘稿保留最新口語說明，獨立 DOCX 講稿維持其最近完成版本。

第三節學生使用 `第3節_指定地點_ODD小組學習單_A4_6組.pdf`，以 A4 單面列印，每組一張；教師解答提供另份 PDF 與 DOCX。

教材中的假設場景、測試數值與 ODD 填寫範例供課堂練習，不代表現地實測結果或業者核准條件。圖片、影片及外部資料的權利依各原始來源說明；本儲存庫不另行宣告整份教材的開放授權。
